# ADR-003: Use Mutable Working State With Immutable Historical Versions

- **Status:** Accepted
- **Date:** 2026-08-24
- **Decision owners:** Product Architect / Technical Lead

## Context

Better Content must preserve historical traceability.

Content DNA changes over time. Content is generated by AI, edited by humans, accepted, and eventually published. Analytics must remain associated with the exact version that was actually published.

Creating a full immutable record for every keystroke would create noise and unnecessary storage, while storing only one mutable record would destroy history.

## Decision

Use two complementary patterns.

### Content DNA

- Stable `content_dna_profile`
- Immutable `content_dna_versions`
- New meaningful saves create a new DNA version
- Idea generation batches reference the exact DNA version used

### Content

- Stable `content`
- One mutable `content_draft`
- Immutable `content_versions`
- Meaningful checkpoints create versions
- Acceptance creates an immutable version and records it as the accepted version
- Publications always reference an immutable content version

The mutable content draft uses a revision number for optimistic concurrency control.

## Consequences

### Positive

- Historical generations remain reproducible and traceable.
- Editing after publication cannot silently change the published source.
- Human edits can later be compared with AI-generated versions.
- We avoid generating a database version on every keystroke.

### Negative

- Application services must explicitly manage snapshot creation.
- Version history adds more tables and lifecycle rules.

## Invariants

- Old DNA versions are immutable.
- Old content versions are immutable.
- A publication never references a mutable draft.
- Editing the current draft never changes an existing publication.
- Changing active DNA never changes historical idea-generation context.

## Rejected alternatives

### One mutable row per content item

Rejected because it destroys historical publishing traceability.

### Snapshot every editor change

Rejected as unnecessarily noisy for V1.
